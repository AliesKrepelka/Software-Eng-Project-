Library Management System
Project Overview

This project is a console-based Library Management System written in C++. It is designed to simulate the core operations of a small library by allowing users to manage patrons, books, and loans through a structured menu-driven interface. The system emphasizes modular design, object-oriented programming, and clean separation of responsibilities across different components of the application.

Functionality

The application allows users to:

Manage patrons (add, edit, delete, and display patron records)

Manage books and track basic book information

Create and manage loans, including tracking which books are checked out

View summarized system data such as patron status, fines, and books checked out

Each major feature is implemented using dedicated classes (e.g., Books, Loans, Patrons) and corresponding collection classes, ensuring the system remains organized, scalable, and easy to maintain.

Team Goal:
The goal of this project is to collaboratively design and implement a fully functional, reliable, and well-structured C++ application that demonstrates real-world problem-solving using object-oriented principles. As a team, our focus is on producing clean, readable code, resolving bugs through iterative testing, and learning effective software development practices such as version control, modular design, and incremental improvement. This project also serves as a foundation for understanding how larger systems manage data, user interaction, and program flow.
